# Pulse Dashboard Codex Plugin

This directory is the GitHub marketplace package for the Pulse Dashboard Codex
plugin. It lets Codex use an already connected COROS MCP service to create a
sanitized health and training snapshot, an AI coaching insight, and a local
Pulse Desktop update through the Handoff bridge.

The desktop app also provides compact widget layouts for quick viewing:

- 16:9 and 4:3 layouts show steps, recorded activity calories for today,
  resting heart rate, and sleep duration in a two-column card grid.
- 21:9 lays out the same four metrics in one horizontal row.

The plugin does not include COROS credentials, a direct COROS API client, or
real user health data. It cannot query COROS from the desktop process: a new
live snapshot must be generated by a Codex task with the COROS MCP connection.
The dashboard buttons only reread the latest local snapshot.

See the repository root README and
[`docs/COMPACT_WIDGET_MODE.md`](../../docs/COMPACT_WIDGET_MODE.md) for
installation, architecture, privacy boundaries, data definitions, and current
Beta limitations.
