# Pulse Roadmap

## 当前唯一优先级：v0.5 桌面看板测试闭环

Pulse 是由大模型宿主驱动的桌面数据看板：COROS MCP 在宿主侧完成授权和查询，Codex 将标准化结果交给 Pulse 桌面版展示。项目不开发独立 COROS OAuth、供应商 API 客户端或账号体系。

### 唯一成功标准

在已连接 COROS MCP 的 Codex 中刷新 Pulse 后，Windows 桌面看板能可靠展示真实健康、今日训练、计划和 AI 训练建议；数据不需要通过聊天文字人工复制。

### P0：桌面看板数据闭环

- [x] 选定首个 LLM 宿主：Codex，并创建 `pulse-dashboard` 个人插件。
- [x] 建立仅限本机的 Codex Handoff：Codex 插件发布标准化快照，Electron 读取并渲染。
- [x] 在设置中支持 `演示数据` / `Codex + COROS MCP` / `自定义 HTTP Bridge` 三种数据源。
- [x] 保持 Electron 与 COROS 凭据隔离，并提供缓存和离线回退。
- [x] 用真实 COROS 数据完成首轮可视化验收，检查字段完整性、刷新提示和训练建议呈现。
- [x] 固化 Codex 插件的发布质量门、失败提示、UTF-8 路径和版本更新说明。
- [x] 插件发布成功后由桌面端即时自动读取，不要求再次点击刷新。

### P1：AI 教练体验

- [ ] 增加可展开的训练建议 / 训练复盘卡片和提问入口。
- [x] 显示快照时间、数据来源状态、旧日期和异常说明。
- [ ] 在 Codex 支持的权限和自动化边界内评估定时发布；不让 Electron 自行调用 COROS。
- [ ] 基于真实数据连续自测，优先修复前三个体验痛点。

### P2：测试分发

- [x] 生成 Windows x64 NSIS 测试安装包，并验证解包版可执行文件与本机 Handoff 启动。
- [ ] 在测试机完成人工安装 / 卸载验收。
- [x] 编写连接、隐私、历史审计与发布检查说明。
- [ ] 创建干净公开分支，经用户确认后上传 GitHub 并开展小范围试用。

## 已完成的基础能力

- [x] Pulse 品牌、桌面窗口、托盘、设置、主题、透明度、置顶、精简模式和内置圆角滚动条。
- [x] 标准化快照、`DataSourceAdapter`、健康检查、超时、响应大小限制、缓存和离线回退。
- [x] 演示数据、自定义 Bridge 协议测试、快照测试、适配器测试和 Electron 渲染检查。
- [x] 验证 Codex 宿主可只读调用真实 COROS MCP 数据。

## 暂缓至测试版稳定后

- 商标清查、商标申请、应用上架和正式发布策略。
- 独立 COROS OAuth、供应商 API 客户端、多数据源直连。
- macOS 签名、自动更新和正式发布工作流。
