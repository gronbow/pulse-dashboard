# Pulse Dashboard v0.5.5 Beta

v0.5.5 Beta 在 v0.5.4 已验证的 Codex + COROS MCP 本地 Handoff 闭环上，补充了更轻量的桌面快速查看模式，并同步更新 Codex 插件的公开说明。

## 新增与改进

- 新增 16:9（360×203）、4:3（360×270）和 21:9（420×180）三种简洁小组件比例。
- 小组件只展示步数、今日已记录活动消耗、静息心率和睡眠时长。
- 21:9 模式将四项指标横向排列；16:9 与 4:3 使用两列卡片布局。
- 统一指标名称、图标、主数值和单位的对齐规则，并放大 21:9 模式中偏小的文字层级。
- 增加三种比例的合成演示截图和自动化 Electron 截图验证。
- 更新 Codex 插件 manifest、README 和技能说明，明确小组件数据口径与同步限制。

## 数据口径

“今日消耗”是当天已记录活动的 `calories` 合计，不代表全天总能量消耗。没有有效活动热量时显示“—”。其他健康指标缺失时同样保留缺失状态，不使用演示数字填充真实模式。

## 已知限制

- 新的即时 COROS 数据仍需由 Codex 任务调用已连接的 COROS MCP 生成；桌面刷新按钮只重读本机最新快照。
- Pulse 仍是 Codex 宿主驱动的桌面看板，不是独立 COROS 客户端、后台采集器或医疗产品。
- 本 Beta 只提供 Windows x64 安装包，当前未签名且没有自动更新。

## 验证

发布候选已通过：

- `npm run test:release`
- 16:9、4:3、21:9 Electron 截图与数据断言
- 公开仓库隐私审计、插件包一致性检查和 Git 历史审计
- Windows 解包版托盘/窗口图标检查
- `npm audit --omit=dev --audit-level=high`：0 个高危生产依赖漏洞
