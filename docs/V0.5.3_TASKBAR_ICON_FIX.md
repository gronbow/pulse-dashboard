# Pulse v0.5.3 Windows 任务栏图标修复

更新时间：2026-07-27

## 问题

源码开发模式通过 `electron.exe .` 启动。即使应用和托盘资源已经包含 Pulse 图标，如果 `BrowserWindow` 没有显式设置窗口图标，Windows 任务栏仍可能继承 `electron.exe` 的默认原子图标。

## 修复

- 创建 `BrowserWindow` 时显式传入 Pulse 原生 ICO。
- 窗口创建后再次调用 Windows `setIcon`，避免无边框窗口继承宿主可执行文件图标。
- 将应用与窗口的 `AppUserModelID` 固定为 `app.pulse.dashboard`。
- 通过 `setAppDetails` 提供任务栏应用 ID、图标文件路径和图标索引。
- 新增 `npm run test:window-icon`，分别验证源码开发态和解包态的窗口身份配置。

## 本地验证

- 开发态窗口运行检查通过，图标来源为 `build/icon.ico`。
- 从正在运行的 Pulse 原生窗口句柄提取到 64×64 Pulse “P” 图标：3172 个可见像素、2411 个绿色像素和 674 个深色像素。
- v0.5.2 打包 EXE 自身原本已包含 Pulse 图标；v0.5.3 进一步保证窗口与任务栏显式使用该图标，而不依赖可执行文件继承行为。
- v0.5.3 解包态窗口检查通过，`app.pulse.dashboard` 从 `resources/pulse-tray.ico` 加载窗口图标。
- 测试安装包：`Pulse-Dashboard-Setup-0.5.3-x64.exe`。
- 安装包 SHA-256：`9853A71E0652F86F5EAB8EB6BB8ECA63E24341914353E8C63569C9F70CDD8617`。
- 当前安装包未做代码签名，仍仅作为 Beta 测试包。
