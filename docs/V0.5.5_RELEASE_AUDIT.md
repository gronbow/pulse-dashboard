## 发布范围

v0.5.5 在 v0.5.4 的 Codex + COROS MCP 本地 Handoff 闭环上，加入：

- 16:9、4:3、21:9 简洁小组件模式。

- 统一指标名称、图标、主数值和单位的对齐规则。
- 21:9 模式的放大文字层级与三种比例合成示例截图。
- 同步更新 Codex 插件 manifest、README 和技能说明。

## 数据与产品边界

Pulse 仍是 Codex 宿主驱动的桌面看板，不是独立 COROS 客户端。新的即时数据必须由 Codex 任务调用已连接的 COROS MCP 生成；桌面刷新按钮只重读本机已发布快照。“今日消耗”只统计当天已记录活动的卡路里，不代表全天总能量消耗。
