# Pulse v0.5.4 日均压力卡片

更新时间：2026-07-28

## 设计依据

Pulse 面向需要长时间坐在电脑前工作、希望少看手机的人群。2026-07-28 的真实 COROS 闭环测试中，日常健康摘要能够提供今日平均压力，而血氧字段长期缺失。继续固定展示“血氧—设备未提供”会浪费最显眼的健康卡片之一。

## 实现

- 快照新增可选字段 `health.stress = { value, unit: "score", date }`，保持版本 1 的向后兼容。
- 次要健康卡片优先显示 COROS 日均压力和真实数据日期；压力缺失时回退显示血氧。
- 桌面端只展示 COROS 原始 0–100 分值，不自行做医疗解释或阈值诊断。
- Handoff 与发布脚本把 1–100 的压力值计为有效健康信号；`0` 仍视为缺失占位。
- Pulse 插件工作流明确从日常健康摘要读取压力，并在洞察中与睡眠、恢复和训练负荷综合判断。

## 验收边界

必须同时验证演示数据、旧快照血氧回退、2026-07-28 真实快照压力显示、Handoff 归一化、插件发布质量门和打包后的 Windows 窗口。

`npm run test:secondary-health` 会在真实 Electron 渲染后断言压力文案和数值，并用不含 `health.stress` 的兼容快照断言血氧回退。`npm run test:packaged` 直接启动解包版可执行文件，避免把开发态图标检查误报为已打包验证。
