# Pulse v0.5.2 Windows 托盘图标修复

更新时间：2026-07-27

## 问题

v0.5.1 在 Windows 系统托盘中可能显示空白圆角占位框。原因不是测试版故意省略图标，而是主进程把 SVG Data URL 直接传给 `nativeImage`；该输入在 Windows 原生托盘路径中可能解析为空图。

## 修复

- 从现有 `build/icon.svg` 生成 16、24、32、48、64、128 和 256 像素的多尺寸 `build/icon.ico`，不改变 Pulse 标志设计。
- Windows 应用和托盘优先使用真实 ICO 文件；安装包额外携带 `pulse-tray.ico`，并携带 PNG 作为文件损坏时的回退。
- 启动时检查资源是否存在、`NativeImage` 是否为空，以及 32×32 采样中是否包含可见、绿色和深色关键像素；无效资源不会再被静默接受。
- 新增 `npm run test:tray`，真实创建 Electron `Tray` 对象。该测试支持开发态和打包后的解包态。

## 验收边界

自动检查可以证明资源有效、像素不是透明占位图，并且 Windows 接受其创建托盘对象。发布前仍需在目标电脑的系统托盘中人工确认图标在实际 DPI 和主题下清晰显示。

## 本地验证结果

- `npm test`、`npm run test:desktop` 和生产依赖审计通过。
- 开发态与 `release/win-unpacked/Pulse Dashboard.exe` 解包态均成功创建托盘对象，并从 ICO 读到 832 个可见采样像素。
- 解包资源包含 16、24、32、48、64、128 和 256 像素的 `pulse-tray.ico`。
