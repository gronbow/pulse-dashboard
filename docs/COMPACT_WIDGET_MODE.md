# Pulse 简洁小组件模式

## 目的

为桌面快速查看提供一个更轻量的横版小窗口。该模式不展示完整看板中的训练详情、趋势和 AI 洞察，只保留四项基础数据：

- 步数
- 今日消耗
- 静息心率
- 睡眠时长

## 尺寸与比例

在 Pulse 设置中打开“简洁小组件模式”，然后选择窗口比例：

| 比例 | CSS 尺寸 | 使用场景 |
| --- | --- | --- |
| 16:9 | 360 × 203 | 更紧凑的横版桌面小组件 |
| 4:3 | 360 × 270 | 需要更多纵向空间时使用 |
| 21:9 | 420 × 180 | 四项指标横向排列的超宽小组件 |

小组件模式会固定窗口尺寸，避免拖拽调整破坏比例；关闭该模式后，会恢复完整看板此前的位置和尺寸。21:9 模式将四项指标放在同一行并提高数字与标签字号；16:9 和 4:3 模式保留两列布局，但会将数值和单位靠右排列，减少卡片右侧的无效留白。所有操作图标使用应用内置 SVG，不依赖系统字体是否包含特殊符号。

## 数据口径

| 展示项 | 数据来源 | 缺失时的表现 |
| --- | --- | --- |
| 步数 | `health.steps.value` | `—` |
| 今日消耗 | 当天已记录活动的 `calories` 合计 | `—` |
| 静息心率 | `health.restingHeartRate.value` | `—` |
| 睡眠时长 | `health.sleep.durationMinutes` | `—` |

“今日消耗”特指当天已记录训练或活动的卡路里合计，不代表全天总能量消耗，也不等同于完整的全天热量统计。没有有效活动热量时不会使用演示值或推算值。

## 数据更新与限制

小组件仍然遵循 Pulse 的本地 Handoff 架构：它只能读取 Codex 与 COROS MCP 同步后写入的本地快照，不能绕过 Codex 直接请求 COROS。点击小组件中的刷新按钮会重新读取本地快照；如果需要获取最新数据，仍需先让 Codex 完成一次 MCP 同步。

如果同步结果中某项数据缺失，小组件会保留缺失状态，不会用其他指标冒充该数据。演示模式也只用于展示界面，不代表真实健康数据。

## 验证

在项目根目录执行：

~~~powershell
npm run test:compact-mode
~~~

该测试会分别以 100%、125% 和 150% 缩放启动 16:9、4:3 和 21:9 模式，检查四项指标、窗口截图尺寸、最小文字层级、横向溢出和中文渲染结果。`npm run test:ui-layout` 另以 150% 缩放验证浅色主题和长文本。
