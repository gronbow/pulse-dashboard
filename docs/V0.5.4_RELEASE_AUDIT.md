# Pulse v0.5.4 发布候选审计

审计日期：2026-07-28

## 结论

v0.5.4 已完成本机发布候选验证，真实链路为：

```text
COROS MCP → Codex Pulse 插件 → 127.0.0.1 Handoff → Pulse Electron 看板
```

桌面端不持有 COROS 密码、令牌或供应商 API 权限。真实快照仅发布归一化健康、训练、计划、七日负荷和洞察字段；坐标、活动内部 ID 与原始 MCP 响应未进入仓库或安装包。

## 已验证项目

- `npm test`：快照归一化、适配器、Bridge、Handoff、发布质量门、UTF-8、隐私与开发态图标检查通过。
- `npm run test:desktop`：真实 Electron 窗口完成渲染并生成截图。
- `npm run test:secondary-health`：有压力数据时显示日均压力；旧快照无压力时回退血氧。
- `npm run test:unavailable`：Codex 首次同步前渲染空指标和明确等待提示；无同源缓存时不回退 Demo，跨 provider 缓存不混用。
- `npm run test:packaged`：直接启动解包版 EXE，托盘图标、窗口图标、`AppUserModelID` 与随包 ICO 通过。
- NSIS 安装包在隔离目录完成静默安装、安装后 EXE 验证、桌面/开始菜单快捷方式检查及静默卸载；卸载后目录、快捷方式和卸载注册项均清理。
- Windows 双屏桌面实际启动验证中，任务栏显示 Pulse 绿色 `P` 图标，不再显示 Electron 默认图标。
- `npm run audit:production`：生产依赖高危漏洞为 0。
- 最终解包版四进程 5 秒采样约占 0.31% 单核（整机约 0.022%），总工作集约 404 MB；CPU 达到原始目标，内存未达到 150 MB 目标并已明确披露。
- ASAR 内容仅包含白名单中的 `src`、本地 Handoff、`package.json` 与许可证。
- 个人插件源的 skill 校验、plugin 校验及 UTF-8 发布器测试通过；已按 marketplace 流程重装 v0.5.4 缓存，并核对 manifest、skill 与发布脚本哈希一致。
- GitHub 首页预览图使用合成数据；CI 增加可达历史与生产依赖审计，并准备隐私优先的 Issue/PR 模板和手动 Windows Release Candidate 工作流。
