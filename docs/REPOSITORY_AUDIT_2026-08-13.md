# Pulse 仓库全面审查（2026-08-13）

审查范围：桌面端、Codex 插件、本机 Handoff、快照契约、发布脚本、GitHub Actions、依赖、公开仓库隐私边界、深浅主题、完整窗口及 4:3 / 16:9 / 21:9 小组件。审查只使用仓库内合成数据；未读取、复制或提交真实健康数据。

## 结论

当前架构适合继续作为 Windows Beta：COROS 权限停留在 Codex 宿主侧，Electron 只接收本机标准化快照；没有发现需要立即停止开发或撤回公开版本的 P0 问题。现有安全基线较完整，包括回环地址限制、Handoff 身份证明与 Bearer 认证、Windows 系统加密缓存、严格 CSP、默认拒绝 Electron 权限、发布文件白名单、固定 GitHub Actions 提交和公开仓库隐私审计。

本轮最高价值问题是“整体快照日期不能代表每项数据日期和来源”。它可能让昨日睡眠、旧恢复值或算术汇总看起来像今天的 COROS 原始值，因此已作为 PR B 在隔离分支实施。

## 本轮已实施：PR B 数据可信度

- 健康、今日训练、训练计划和负荷逐项显示日期与来源；日期未知、旧数据和缺失值采用明确文字，不用颜色单独传意。
- 4:3、16:9、21:9 小组件只在单位行显示短日期，完整来源放入可访问名称和悬浮说明，避免信息密度反弹。
- `provenance` 限制为隐私安全枚举；传输路径与指标来源分离，未知值默认关闭推断。
- 动态洞察标签和活动列表由 DOM 文本节点构建，不再拼接 HTML 字符串。
- Handoff JSON 响应增加 `X-Content-Type-Options: nosniff`。
- 公开插件增加独立加载回归，避免插件包错误依赖桌面端源码目录。
- README、桥接契约、路线图、需求矩阵、开发状态、候选说明和合成截图已同步更新。
