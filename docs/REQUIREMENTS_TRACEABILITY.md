# Pulse 原始需求追踪矩阵

更新时间：2026-08-03

本文件将最初 PRD、V0.3 工程建议、V0.4 计划和最终采用的 V0.5 Plugin 路线映射到当前实现。V0.5 是有效架构基线：COROS 授权和工具调用属于 LLM Host，Pulse Desktop 不自行实现 OAuth 或供应商 API。

状态说明：

- **已完成**：代码、自动化测试或本机运行证据足以支持 Beta。
- **架构调整**：原条目被 V0.5 明确替代，不应按独立 App 方案实现。
- **后续**：有产品价值，但不是首个真实 MCP 桌面闭环的阻塞项。
- **外部验证**：代码已准备，仍需要另一环境或用户操作。

## 核心闭环

| 原始目标 | 状态 | 当前实现与证据 |
|---|---|---|
| 大模型通过 COROS MCP 获取真实数据 | 已完成 | Codex `pulse-dashboard` skill 读取健康、睡眠、恢复、活动、课表和七日负荷；2026-07-28 已完成真实快照发布和桌面截图验收。 |
| 数据必须出现在桌面，而不是只留在对话文字中 | 已完成 | 插件发布标准快照到 `127.0.0.1:19091`；Handoff 的 `snapshot-updated` 事件通知 Electron 立即重读。 |
| 展示身体状态、今日训练和训练计划 | 已完成 | `src/snapshot.js` 归一化健康、活动和计划；真实 Electron 渲染测试覆盖训练、健康与计划卡片。 |
| 展示最近一周负荷 | 已完成 | `trends.trainingLoad` 保留最多七个逐日点；演示夹具和校验器要求七个点，真实快照也已验证七日数据。 |
| 生成每日 AI 训练洞察 | 已完成 | 洞察由 Codex 基于同一次 MCP 查询生成并随快照发布；Handoff 要求非占位洞察，桌面显示训练参考免责声明。 |
| 缺失数据不能伪造成 0 或 Demo | 已完成 | 归一化把非法占位值变为 `null`；质量门拒绝零时长活动；Codex/Bridge 无同源缓存时显示 `unavailable` 空快照，绝不回退合成健康数字。 |
| 离线时保留上一次成功数据 | 已完成 | 仅复用相同 provider 的快照缓存；跨数据源缓存不会被改名后冒充当前数据。 |
| 无感刷新 | 部分完成 | 新快照发布后桌面即时自动读取，按钮和托盘均明确为“读取最新同步”；Electron 不能继承 Codex MCP 权限，因此首次/新数据查询仍需发生在 Codex 任务中。 |

## 原 PRD 功能条目

| 条目 | 状态 | 说明 |
|---|---|---|
| F-01 OAuth 登录 | 架构调整 | V0.5 明确废弃桌面独立 OAuth；授权留在 Codex/COROS MCP。 |
| F-02 健康、训练、计划数据 | 已完成 | 当前快照含睡眠、静息心率、HRV、恢复、步数、压力/血氧、活动、计划和负荷。日总卡路里若 MCP 未提供则保持缺失。 |
| F-03 定时刷新、手动刷新、缓存 | 部分完成 | 本地快照轮询、发布事件、手动重读和缓存已完成；不声称能无任务痕迹地定时调用 Codex。 |
| F-04 健康卡片 | 已完成 | 指标卡、独立数据日期和缺失占位可用；日均压力优先，缺失时回退血氧。 |
| F-05 今日训练 | 已完成 | 支持零次或多次活动列表及距离、时长、配速、心率、卡路里汇总；折叠交互列为后续。 |
| F-06 今日课表 | 已完成 | 保留实际 `plan.date`，可区分明确休息日、无计划与最近下一课。 |
| F-07/F-08 AI 洞察与重生成 | 架构调整后完成 | Codex 负责重新查询与生成；桌面“读取最新”不会伪装成一次新的模型调用。 |
| F-09 窗口形态 | 已完成 | 无边框、圆角、拖动、缩放、置顶和透明背景。 |
| F-10 主题、透明度、精简模式 | 已完成 | 深色、浅色、跟随系统、40%–100% 透明度、完整看板和 16:9/4:3/21:9 简洁小组件模式。 |
| F-11 系统托盘 | 已完成 | 显示/隐藏、读取最新同步、设置、退出；已验证安装后托盘和任务栏 Pulse 图标。 |
| F-12 开机自启 | 已完成 | 安装包支持用户开启；Beta 默认关闭，避免未告知的后台启动。 |
| F-13 账号、卡片开关、语言 | 后续 | 账号管理已归属宿主；卡片显隐和中英文本地化不是首个闭环阻塞项。 |

## 非功能与发布

| 条目 | 状态 | 说明 |
|---|---|---|
| CPU ≤ 1% | 已完成 | v0.5.5 发布候选 5 秒采样约占 0.31% 单核（整机约 0.022%）。 |
| 内存 ≤ 150 MB | 后续 | Electron 四进程本机实测约 404 MB，已在发布清单披露；真实链路稳定前不迁移框架。 |
| 失败优雅降级 | 已完成 | 超时、响应上限、JSON 校验、同源缓存和无缓存空状态均有覆盖。 |
| 凭据与隐私 | 已完成 | Desktop 不保存 COROS 凭据；Handoff 仅回环监听，拒绝浏览器来源写入，公开审计排除坐标、ID、FIT、Token 和真实快照。 |
| Windows 10/11 x64 | 已完成/外部验证 | Windows 11 已完成打包、安装、卸载、托盘和任务栏验收；另一台 Windows 测试机仍待验证。 |
| macOS | 后续 | V0.5 Beta 仅发布 Windows；签名与 DMG 延后。 |
| DPI 125%/150% | 外部验证 | 使用多尺寸 ICO 和响应式窗口；仍需不同缩放比例人工复测卡片文字。 |
| GitHub Beta | 外部验证 | v0.5.5 干净公开分支、历史审计、CI、模板、三种简洁小组件合成截图、安装包和源码归档已准备；等待 Draft PR 合并和 Release 验证。 |

## V0.3/V0.5 后续能力

- 桌面内 AI 教练输入框、多轮对话和训练复盘展开卡片：P1。
- Codex 宿主允许的低打扰自动发布：持续评估，但不绕过权限或伪装成无任务后台调用。
- 数据源级字段来源标签、卡片显隐、多语言和“关于 Pulse”：P1/P2。
- 多品牌直连、独立 OAuth、商标申请、macOS 签名和自动更新：测试版真实闭环稳定后再评估。

## 当前发布阻塞项

代码侧没有已知 P0。首次 GitHub Beta 前仍需：

1. 在新的 Codex 任务中实际触发已重装的 v0.5.5 skill。
2. 完成 Draft PR 审阅、合并和 v0.5.5 Release 资产验证。
3. 后续在另一台 Windows 设备完成交互式安装与 DPI 复测。
