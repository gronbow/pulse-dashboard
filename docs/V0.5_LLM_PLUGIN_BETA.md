# v0.5 LLM Plugin 测试版实施说明

## 目标

开发 Pulse 作为大模型健康教练的桌面看板。利用 Codex 已跑通的 COROS MCP 路径取得真实数据，由桌面端展示，并将基于当前数据的训练建议呈现为卡片。

## 架构决策

- Pulse 不是独立 COROS 数据监测应用，也不直接连接供应商 API。
- COROS 授权、查询、清洗、模型推理和训练建议由 Codex 处理。
- Pulse 的主要交互面是 Electron 桌面看板，而不是 Codex 对话文本。
- Codex 插件将规范化快照发布到仅限本机的 Handoff；Electron 读取该快照并渲染，无需获得 COROS 凭据。

## P0 数据闭环

1. **Codex 宿主**：复用当前已连接的 COROS MCP 工具。
2. **标准化快照**：将健康、今日活动、计划、负荷、趋势和洞察整理为 Pulse 快照；指标携带各自数据日期，最近七日短期/长期负荷按天保留。
3. **本机交接**：插件向 `127.0.0.1:19091/api/snapshot` 发布快照；Pulse 读取 `GET /api/snapshot`。
4. **桌面数据源**：设置页支持切换到“Codex + COROS MCP”，不需要填写 COROS API、账号或 Token。
5. **真实数据验收**：桌面卡片展示真实数据和训练建议，且上游暂不可用时保留最后一次有效快照。

详细协议见 [桌面交接约定](BRIDGE_CONTRACT.md)。

## P1 AI 教练卡片

- 展开查看今日训练建议和训练复盘。
- 显示建议生成时间、数据来源状态和失败提示。
- 后续仅在 Codex 权限边界内增加定时发布或通知，不让桌面端直接访问 COROS。

## 测试版验收

| 场景 | 通过标准 |
|---|---|
| 真实数据 | Codex 发布的 COROS MCP 快照能在 Pulse 桌面卡片中展示健康、活动、计划、当前负荷和最近七日负荷。 |
| 数据时效 | 当天指标尚未归档时显示带日期的最近有效值，不以 `0` 或未标注旧值冒充今日数据。 |
| AI 建议 | 建议来自 Codex 已授权的数据上下文，不由 Pulse 伪造。 |
| 隐私 | Pulse 不保存供应商密码或 Token；交接只走本机回环地址。 |
| 失败回退 | Codex 或 COROS MCP 暂不可用时，有明确状态提示且保留最后有效快照。 |

## 当前范围外

商标清查与申请、应用上架、独立 OAuth、第三方 API 客户端和多平台正式分发，都在测试版完成真实数据闭环后再评估。
