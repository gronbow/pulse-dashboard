# Pulse v0.5.1 完成度审计

审计日期：2026-07-27
审计范围：原始桌面看板规格、v0.5 LLM Plugin 方案、当前源码、真实 COROS MCP 闭环、Windows 运行与发布准备。

## 发布结论

Pulse v0.5.1 已达到“Codex 宿主 + COROS MCP + Windows 桌面看板”的源码测试版标准，可以在用户确认后作为 GitHub Beta 发布。

它尚不应被描述为：

- 能脱离 LLM 宿主独立登录或查询 COROS 的应用；
- 能在完全无 Codex 任务记录的情况下后台调用 MCP；
- 已达到应用商店、代码签名、macOS 分发或 150 MB 内存目标的正式版本。

## 原始规格的架构调整

原始规格中的独立 OAuth、供应商 REST API、Token 刷新和账号管理不再属于 Pulse v0.5。根据后续明确的 Plugin 路线，这些职责由 LLM Host 与其 COROS MCP 连接承担；Pulse 只接收脱敏标准快照。

“自动刷新”在当前版本分为两层：

1. Pulse 自动读取本机新快照并立即更新窗口，不产生新 Codex 任务。
2. 从 COROS 获取全新数据仍需 LLM Host 的授权工具调用。Codex 计划任务会留下可见记录，因此项目默认不启用并不宣称完全无感。

- `npm run audit:production`：生产依赖 0 个已知漏洞。
- 真实 Electron 顶部与趋势区域截图通过；七日负荷、指标日期、圆角窗口和内置滚动条均完成视觉检查。
- 干净公开分支 `codex/public-beta` 的 `npm run audit:history` 通过。
- Windows 当前机器空闲 CPU 采样约为 0%，Electron 四进程工作集约为 386 MB。后者高于原始 150 MB 指标，已登记为 Beta 限制。

## GitHub Beta 前仍需完成

1. 用户在 Codex 中连接 GitHub 账号，并确认仓库名称及 Public/Private 可见性。
2. 仅推送 `codex/public-beta`，不得推送保留私人旧历史的开发分支或其他本地引用。
3. 人工完成安装器安装/卸载测试；未完成前，Release 应明确标记为未签名测试包。
4. 上传后复核默认分支、公开文件和 Release 资产中没有真实健康数据。
